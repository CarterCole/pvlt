# pvlt-server

The pvlt server and command: TLS 1.3 listeners, an OPV-compatible API, and unseal and seal.

Part of [pvlt](../../README.md), a PII vault that erases by destroying keys.

> **Pre-alpha. Do not use with real personal data.** There has been no independent security review and the
> format is not frozen. See the project README and `docs/DECISIONS.md` for the gates that are not yet met.
